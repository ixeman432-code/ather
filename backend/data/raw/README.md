\## الإجابات المطلوبة



هل يوجد حقل لدرجة الحديث؟

نعم، يوجد حقل باسم: الدرجة.



هل توجد ترجمة إنجليزية؟

نعم، يوجد حقل باسم: الترجمة الإنجليزية.



هل النص يحوي السند كاملاً أم المتن وحده؟

نص العرض مخصص للنص الذي سيُعرض للطفل، وتوضح خطة المشروع أن النص المعروض يكون بالمتن دون السند.
